| 同期总量 | 全区 **13,726 件**（含归属街道为空，用于全区/全市对比）｜13 街镇明细合计 **13,719 件**（用于街镇合计与街镇间对比），相差 7 件即归属街道为空 |

## ⚠️ 维护约定

1. **改数据必须改脚本再重跑**，不要直接编辑 HTML / docx 产物。
2. **口径变更三处同步**：`scripts/audit_consistency.py` 基准表 → 《网页版整改清单》第八节 →《成果汇编》编制说明 / 第 2 章 / 附录 A。
3. **提交前跑 `scan_pii.py`**；输入数据与公民个人信息一律不入库，`git add` 逐项指定路径，**禁用裸 `git add -A`**。
4. 成果总览的分类计数（「N 项已完成 · 含 M 项附件」）由脚本生成，**禁止手填**。
5. 本仓库为 **public**，任何写入前先确认内容不含个人信息与非公开原始数据。
